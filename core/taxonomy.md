# Taxonomy

Two layers. Every card carries both.

## STEEP (always)

One of `social`, `technological`, `economic`, `environmental`, `political`.
Pick the layer where the *change* happens, not where the effect lands: a law
about batteries is `political`; a battery chemistry is `technological`.

## Technology (`tech[]`)

**Connected:** Envisioning maintains a taxonomy of ~1,000 named technologies
with lineage (what it depends on, what it enables) and maturity. Resolve names
with `search("<term>")` before writing `tech[]`; use the canonical title. If
no entry exists, keep the free-text name and add `taxonomy: unresolved` to
frontmatter so it can be reviewed.

**Standalone:** free text, singular, lowercase, no vendor names
(`solid-state battery`, not `QuantumScape cells`). Prefer the capability over
the product.
